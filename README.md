# GameNet-Management-System
سیستم GameNet یک نرم‌افزار دسکتاپ توسعه‌یافته با Python و Tkinter برای مدیریت یکپارچه گیم‌نت‌ها است. این برنامه امکان ثبت مشتریان، مدیریت دستگاه‌ها، کنترل زمان بازی، محاسبه خودکار هزینه‌ها و تولید گزارش مالی (خروجی CSV) را فراهم می‌کند. معماری سیستم سه‌لایه است و برای سرعت بیشتر، داده‌ها در فایل‌های JSON ذخیره می‌شوند.
